# 編集リズムの実動画検証（2026-09-16）

ニューギニアの約23分50秒の動画をローカルで処理した試作版です。
APIによる映像・台本の再分析は行っていません。

## 確認できた改善

従来のFFmpeg scene threshold=0.30では14点のみを検出しました。
字幕を除いて感度を上げても、ディゾルブの見逃しや演出の重複検出が残りました。

新方式は30fpsに変換した連続映像をTransNet V2で処理し、10fpsの領域差分と
位置合わせを追加します。1イベント内の隣接する反応をまとめ、背景切替、
徐々に切り替わる候補、部分変化、動き、判別保留に分けます。
下部字幕のある本動画では、画面上80%を解析しました。

| 確認した例 | 新方式での結果 |
| --- | --- |
| 00:10付近 地図から歩行者へのディゾルブ | 候補を検出 |
| 00:17付近 人物から森林へのワイプ | 領域差分で候補を検出。種類は保留 |
| 00:25付近 森林空撮から森林内部へのディゾルブ | 候補を検出 |
| 12:23付近 人物写真から木へのディゾルブ | 候補を検出 |
| 12:28付近 ブラーを伴う背景切替 | 1つの背景切替候補として検出。ブラーの種類・長さは未確定 |
| 12:39付近 アイコンから動物写真への交換 | 背景切替と分け、部分変化の候補として検出 |

上の6例は既知の不具合の照合です。無作為抽出した正解率ではありません。
全編の正解表は未作成であり、検出候補の総数を実際の編集数とみなせません。

## 別区間で残った課題

05:00–05:45の照合で、背景の動きと重なった画像挿入を一つにまとめすぎる
処理を修正しました。その後15:00–15:30でも照合しました。
後者では背景切替と写真追加を拾えましたが、短い間隔の画像追加がまとめられたり、
判別保留になる例が残っています。これらの区間の目視確認は1秒間隔の画像に
基づき、すべての編集点をフレーム単位で確定した検証ではありません。

台本・背景の内容が変わった意味や、音楽と編集の同期は、この処理では評価しません。
自動候補の前後画像と差分画像、元動画を照合して確認結果を記録してください。

## 実行確認

- Linux / Python 3.12 / CPUで実動画を処理。
- 公式TensorFlow重みを公式スクリプトで変換。PyTorchとの出力の数値照合を実施。
- 短い動画、推論窓の末尾、連続した反応、近接した別カット、パン、部分挿入、
  日本語ファイル名の動画入力を自動テストで確認。
- 結果HTMLのJavaScript構文、DOM構築、候補の絞り込み、照合状態の変更を確認。
- Windows実機、GPU、ブラウザーの実描画・動画再生は未検証。
