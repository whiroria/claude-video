# Windowsで画面から分析する

これは自分のPCで動くデスクトップ版です。Pythonとffmpegが既に使える環境を前提とします。初回のインストールを自動化するものではありません。

1. ZIPを展開し、`skills` → `watch` フォルダを開きます。
2. `Start-Analyzer.bat` をダブルクリックします。開いた黒い画面は、アプリを使っている間は閉じないでください。
3. 「動画 / YouTube URL」の「選ぶ」で動画を指定します。YouTube URLを貼り付けることもできます（yt-dlpが必要）。字幕だけでは分析できません。
4. 字幕がある場合は「字幕」の「選ぶ」でVTT等を指定します。字幕がない場合は既存の取得・文字起こし処理を使います。文字起こしは別途設定・API利用が必要になる場合があります。
5. OpenAI APIキーを入力します。入力内容は伏せ字で表示されます。入力キーは子プロセスの環境変数で渡し、アプリはキーの設定ファイルを作成しません。空欄なら既存の環境変数やwatch設定を使います。
6. 「分析する」を押します。AI分析は字幕・抽出画像等をOpenAIへ送信し、API料金が発生します。「ローカル計測のみ」を選ぶと、ローカル動画の映像・音量等を計測し、AI台本分析は行いません。
7. 終了後、ブラウザに結果が開きます。後で「結果を開く」でも開けます。

結果は `C:\Users\ユーザー名\VideoEssayAnalyzer\results` の実行ごとのフォルダに保存します。「保存先を開く」ボタンで探せます。JSONとHTMLを保存し、この画面からの実行はSQLiteに登録しません。以前の結果は上書きしません。

## 音声・音楽の区間推定（任意）

ローカル動画を選び、既存の `yamnet.onnx` と対応する `yamnet_class_map.csv` をそれぞれ指定すると全音声を追加分析します。Python環境にnumpyとonnxruntimeが必要です。モデルや追加ライブラリは自動取得しません。設定しない場合も基本分析は動きます。追加分析に失敗した場合は画面に通知し、基本分析の結果を残します。

## 現時点の範囲

* 進捗表示は処理中・音声分析中・終了の段階表示です。残り時間の予測はありません。
* 分析中は重複実行と終了操作を止めます。キャンセル機能は未実装です。
* 結果の一部が未実施の場合、完了とは区別して表示します。CLIP等の追加モデルはこの画面では設定できません。
* 結果画面の動画再生には、ブラウザ側でも同じ元MP4を選んでください。
* Windowsの実画面での動作は利用者のPCでの確認が必要です。短い合成動画による分析・HTML出力をテストしています。
* `Start-Analyzer.bat` で起動できない場合は、黒い画面のエラーを確認してください。PythonのTcl/Tkが必要です。
